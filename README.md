# Roland Kreiter — Portfolio

Premium Portfolio-Entwurf für den Industrial Designer Roland Kreiter.

## Lokal ansehen

```bash
python3 -m http.server 4173
```

Danach `http://localhost:4173` öffnen.

## Veröffentlichung

Der Entwurf ist absichtlich mit `noindex, nofollow` versehen. Vor der Liveschaltung:

1. Profil, Vita und Awards von Roland Kreiter freigeben lassen.
2. Bildnutzungsrechte klären oder die Recherchebilder durch freigegebene Assets ersetzen.
3. Impressum und Datenschutzhinweise mit bestätigten Angaben ergänzen.
4. `noindex, nofollow` entfernen.

Die vollständigen Quellen- und Freigabehinweise stehen in [SOURCES.md](SOURCES.md).
